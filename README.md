# 知华·有据

**华为 PC 场景营销智能体 · AI+X 破界黑客松 / 华为产业落地赛道**

面向门店导购与内容运营，把“理解需求—查找资料—选择图片—组织内容—核验结果”放进同一工作台。ima 仅提供产品事实与图片；本项目自行实现任务解析、场景和平台策略、图文生成、证据校验与营销表述检查。

- GitHub：https://github.com/TroyeXie/huawei-pc-marketing-agent
- 魔搭创空间：https://www.modelscope.cn/studios/TroyeXie/huawei-pc-marketing-agent

## 产品特色

1. **先明确任务**：产品、人群、场景、平台四项输入；“MateBook 14”等模糊型号先追问版本。
2. **只读指定共享库**：按完整名称发现“任德耀新建华为PC知识库”；搜索无结果时回退目录；优先产品事实与限制原文，排除现成营销成稿。
3. **场景与平台共同决定内容**：开学季从学习与携带切入，职场办公从会议和差旅切入，门店到访聚焦一个可体验卖点。公众号、小红书、朋友圈、海报分别规定结构、语气、配图数量与行动引导。
4. **事实先行**：模型从原文提取带短引的事实，程序核对引文在原文中存在，随后才生成标题、正文和配图方案。
5. **交付前独立核验**：独立模型阶段检查语义依据；程序检查参数与单位、无依据价格、绝对化宣传、虚假体验、全面兼容承诺等。无依据内容删除，剩余风险阻止成稿交付。
6. **图片可追溯**：只接受共享库按机型目录取得的图片；保留图名、来源、机型和插入位置，不从全量图库随意取图。
7. **改写与导出**：更换人群、场景、平台或补充修改要求后重新运行；成功结果可复制或导出 Markdown。

## 本次比赛的开发内容

沿用此前“求是·智汇”工作台对清晰输入、结构化结果与来源保留的交互经验，本项目独立实现华为 PC 营销业务流程，使用 Python/FastAPI 和无需构建的原生前端。原学术汇报项目及个人答辩材料没有作为本赛道作品提交。

## 运行

Python 3.12。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
# 将 .env.example 中的变量填入私有运行环境；不要提交真实值。
python app.py
```

打开 `http://localhost:7860`。程序从进程环境读取配置；仅复制 `.env.example` 为 `.env` 不会自动加载。

| 变量 | 说明 |
|---|---|
| `IMA_OPENAPI_CLIENTID` | 已加入指定共享库的账号 Client ID，私密配置 |
| `IMA_OPENAPI_APIKEY` | 同账号 ima API Key，私密配置 |
| `MODEL_API_URL` | OpenAI 兼容的 HTTPS 完整 `/chat/completions` 地址 |
| `MODEL_API_KEY` | 模型服务访问凭证，私密配置 |
| `MODEL_NAME` | 提供方返回的实际模型 ID |
| `MODEL_TIMEOUT_SECONDS` | 单次模型调用超时，默认 55 秒 |
| `IMA_DATA_MODE` | 当前演示默认 `verified_cache`；接口额度恢复后可配置 `live` 重新检索，失败时明确回退到已核验缓存 |
| `PORT` | 默认 7860 |
| `MAX_CONCURRENT_RUNS` | 默认同时 2 个任务 |
| `MAX_RUNS_PER_HOUR` | 默认每来源每小时 24 次 |
| `ZHIHUA_RUNTIME_DIR` | 程序运行记录与选中图片目录，默认 `/tmp/zhi-hua-runtime` |

本次验证使用魔搭官方 API-Inference 中的 `deepseek-ai/DeepSeek-V4.1-Flash`。模型 ID 与配额以服务方实际返回为准。未配置模型或 ima 时，界面明确提示，不返回静态样例冒充生成成功。

在魔搭创空间选择 Docker，上传本仓库源文件，端口为 `7860`。凭证只放创空间私密环境变量，不能写入源码、README、构建参数或截图。健康检查为 `/healthz`。应用无登录门槛，评委可直接访问工作台；服务端不将凭证回传到浏览器。

## 自研 Agent 架构

任务解析确定完整型号、人群、场景与平台。ima 只读接口检索事实原文和同型号图片；搜索为空时回退目录。已确认公开且与本轮资料一致的必要摘录进入模型，原子事实必须通过原文短引核对。图文生成后，再由独立语义核验与确定性规则共同检查；通过后交付，信息缺失或残留风险则暂停并说明原因。

- `app.py`：HTTP 接口、并发控制、选中图片路由、导出。
- `ima_client.py`：只读共享库适配、型号筛选、目录回退、原文及图片获取。
- `engine.py`：可解释策略、三阶段模型调用、事实与合规检查。
- `public_evidence.py` 与 `data/`：将本轮 ima 材料限定为已与华为公开资料核对一致的内容；未确认的整理稿不会传给模型。
- `prompts/system_prompt.md`：角色任务、场景理解、平台规则、知识库约束、图片规则、生成要求、核验规则、合规规则八个模块。
- `static/`：工作台、图文结果、来源与核验界面。
- `examples/`：经确认的实际运行结果索引；不打包原始知识库。

## 实际运行结果

工作台“运行案例”包含三组已保存的真实模型结果。三例都使用同一完整型号，各执行原文事实提取、场景图文生成、独立语义核验三次模型调用；正文、图片、依据、核验与原始时间可一并回看。

| 场景与平台 | 经原文引用核对的事实 | 正文采用事实 | 配图 | 生成与核验耗时 |
|---|---:|---:|---:|---:|
| 开学季 × 小红书 | 22 | 8 | 3 | 32.065 秒 |
| 职场办公 × 公众号 | 14 | 7 | 3 | 33.523 秒 |
| 门店到访 × 朋友圈 | 14 | 3 | 1 | 21.046 秒 |

计时针对实际 ima 接口已取回的材料，不包含再次检索时间。三例均通过本轮原文、语义、数字、图文与合规检查，这不代表覆盖所有营销风险。历史案例图片的稳定展示地址与 ima 取回文件 SHA-256 完全相同。

`examples/verification.json` 另记录 22 项文案规则与预检、11 项公开输入边界检查，33 项均符合预期；这些是实际本地确定性检查，不是模型生成案例。包括模糊型号、无依据权益、否定句保留、转折后的兼容承诺、图片字节伪造与原文版本限定缺失。

## 知识来源与边界

当前完成公开来源核对的机型为 **MateBook 14 酷睿 Ultra** 和 **HUAWEI MateBook Pro**。Ultra 有 3 张独立构图并完成三平台真实生成；Pro 有 1 张可用图，仅适合朋友圈或海报等单图任务，尚未计入正式生成案例。其余型号显示为“来源待核对”，不会用近似型号的事实或图片补齐。每次新任务须绑定实际 ima 检索材料或标明时间的已核验缓存；已核对的公开参考只用于检查实际取回的原文。2026-10-18 ima 返回当日资料读取次数上限后，演示改用本次实际取回并通过核验的缓存；原始检索时间随每次结果保留，模型仍在每次任务中重新生成并核验。资料发生变化、版本限定缺失或图片字节不匹配时，系统会排除该项或停止生成。

ima 接口为官方 `ima-skills-1.1.10` 文档所述只读 OpenAPI。共享库的返回字段兼容 `kb_id/kb_name`；搜索为空不直接推断无权限。资料与图片通过 `get_media_info` 返回的临时入口下载，专用下载请求头与账号 API 凭证分开。

图片匹配依据完整产品目录与来源记录，不承诺仅靠外观识别所有相近机型；生成稿可逐图预览。程序不会公开原始知识库、共享库内部 ID 或媒体下载签名，不提供任意 ima 查询代理。产品价格、活动补贴、软件兼容性等若没有明确原文支持，不作承诺。原文冲突会阻止相关输出，建议由业务人员确认销售版本后发布。

本项目为参赛原型，包含规则与模型核验，但不保证识别全部风险。真实资料检索、网络和模型响应耗时会影响等待时间；服务方限流或空间休眠时需稍后重试。示例记录属于实际历史运行。当前现场生成使用已核验的真实 ima 缓存，原文检索时间标注为 2026-10-18；界面明确说明缓存状态。缓存只含经过公开来源核对的必要章节与选中产品图。
