# 知华·有据

**华为 PC 门店增长智能体 · AI+X 破界黑客松 / 华为产业落地赛道**

从一条客户任务出发，完成五维洞察、平台图文、四档报价示算、180 秒产品演示和第 1 / 3 / 7 天跟进草稿。ima 提供产品事实与图片；自研程序负责场景与平台策略、模型编排、原文引用核对、图文匹配、规则检查和门店执行方案。

- GitHub：https://github.com/TroyeXie/huawei-pc-marketing-agent
- 魔搭创空间：https://www.modelscope.cn/studios/TroyeXie/huawei-pc-marketing-agent

## 使用流程

1. 选择完整机型、目标人群、业务场景和平台。人群与场景支持精简下拉及自定义；可补充预算、必用软件和已表达顾虑。
2. 读取该型号的产品事实及图片，核对华为官网规格和图片文件。模糊型号先追问；不借用相近机型补齐参数。
3. 三个模型阶段依次提取带原文引用的事实、生成原创图文、执行独立语义检查，程序另检查数字、绝对化宣传、价格和兼容承诺。
4. 交付图文与门店执行方案。通过项默认折叠；事实采用紧凑表格并保留出处。可复制、按临时要求重新生成或导出 Markdown。

八类业务场景：开学季、职场办公、内容创作、家庭换新、企业采购、门店到访、新品首发、节日营销。

| 平台 | 内容策略 | 配图要求 |
|---|---|---|
| 小红书 | 口语标题、具体困扰、短段场景、话题标签 | 3-6 张 |
| 公众号 | 标题、导语、任务分段、解释与行动引导 | 2-4 张 |
| 门店朋友圈 | 一个场景、一个核心卖点、咨询引导 | 1-3 张 |
| 门店海报 | 主副标题、不超过 3 个卖点、行动引导 | 1 张 |

## 门店执行方案

- **客户洞察**：使用任务、预算与价值、决策阶段、顾虑与障碍、设备与体验环境五维逐条保留输入依据；没有提供的信息列为待确认。
- **四档报价**：标准方案、门店优惠、优惠组合、完整权益。录入具体 SKU、基础金额和来源，逐项填写权益金额、条件、有效期及叠加关系；使用 Decimal 计算并列出扣减过程。缺少来源或冲突条件时不补写成交价。最低金额仅比较已填报且可计算的方案。
- **180 秒演示**：六个时段安排需求确认、版本核对、实际任务、设备连接、携带体验及下一步；能引用的规格关联本次已验证事实。
- **1 / 3 / 7 天跟进**：依次补齐未确认项、回应顾虑和方案、征求继续联系意愿。输出为草稿，不自动联系客户。

当前赛题资料中的价格卡没有实际四级商业政策。报价模块是有来源输入的算术计算器，不将测试金额当作真实销售报价；尚无真实订单数据证明达到赛题“准确率至少 95%”目标。

## 资料与机型

采用指定共享库“任德耀新建华为PC知识库”，并支持同内容的个人 ima 知识库作为备用。保留本次真实取回并与华为公开资料核对的必要缓存，以应对接口额度或网络波动。缓存与实时检索的来源类型、取材时间保存在结果内；新任务仍重新调用模型生成与核验。

十款完整机型覆盖鸿蒙 MateBook 14、MateBook Pro、Pro S、Fold 非凡大师，MateBook 14 酷睿 Ultra、D 14 2024、D 16 2024、D 16 SE 版 2024、GT 14、X Pro 酷睿 Ultra 微绒典藏版。系统、配置与版本限定随事实保留；公开目录中的完整名称为实际输入准则。

华为官网和华为商城用于核对公开规格与官方图片。原始知识库压缩包、私人账号标识和访问凭证不进入公开仓库。动态价格、活动资格、库存和软件兼容结论需有对应来源。

## 技术结构

| 文件 | 职责 |
|---|---|
| `app.py` | HTTP 接口、输入校验、缓存装载、图片路由与导出 |
| `ima_client.py` | ima 只读检索、目录回退、型号绑定和媒体获取 |
| `public_evidence.py`、`data/` | 对照官方公开规格、原文及图片 SHA-256 |
| `engine.py` | 三阶段模型调用、场景平台策略与生成核验 |
| `growth.py` | 五维输入依据、Decimal 报价、180 秒演示及跟进草稿 |
| `prompts/system_prompt.md` | 角色、场景、平台、知识、图片、生成、核验、合规与门店执行约束 |
| `static/` | 原生前端，无构建依赖；轻量 CSS 3D 动效和减少动态效果支持 |
| `examples/` | 已保存的真实图文运行结果与检查记录 |
| `tests/` | 报价边界、条件冲突与门店方案行为测试 |

## 运行与部署

Python 3.12。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
# 在私有进程环境配置下表变量
python app.py
```

访问 `http://localhost:7860`。程序读取进程环境，复制 `.env.example` 不会自动加载配置。

| 变量 | 说明 |
|---|---|
| `IMA_OPENAPI_CLIENTID`、`IMA_OPENAPI_APIKEY` | 已加入知识库的账号凭证，仅保存在私密环境 |
| `MODEL_API_URL` | HTTPS 完整 `/chat/completions` 接口 |
| `MODEL_API_KEY`、`MODEL_NAME` | 模型凭证和服务方实际模型 ID |
| `IMA_DATA_MODE` | 默认采用已核验缓存；`live` 尝试实时取材并在失败时使用可用缓存 |
| `MODEL_TIMEOUT_SECONDS` | 模型单次超时，默认 55 秒 |
| `PORT`、`ZHIHUA_RUNTIME_DIR` | 默认 7860、`/tmp/zhi-hua-runtime` |
| `MAX_CONCURRENT_RUNS`、`MAX_RUNS_PER_HOUR` | 默认并发 2、每来源每小时 24 次 |

本次模型为魔搭官方推理服务的 `deepseek-ai/DeepSeek-V4.1-Flash`。未配置服务时返回明确状态，不把固定样例作为新生成。

```bash
docker build -t zhi-hua-agent .
docker run --rm -p 7860:7860 --env-file /private/path/agent.env zhi-hua-agent
python -m unittest discover -s tests -v
```

魔搭选择 Docker，应用端口 7860，健康检查 `/healthz`。凭证只放私密环境变量。应用供评委直接打开，生成接口不回传模型或 ima 凭证。

## 实际运行与验证

保留三组真实历史图文：开学季小红书 3 图、职场办公公众号 3 图、门店到访朋友圈 1 图；均经过三阶段模型调用。历史结果与当前现场生成在界面分别呈现。案例原始记录完整保留；界面采用有修订标记的发布整理版，删去重复核对套话与一处无依据体验措辞，复制和导出保持一致。原 33 项规则与输入边界检查、9 项屏幕效果专项回归保留原始计数；新增报价与门店方案测试独立记录，不将程序测试数量换算成模型准确率或成交效果。

图文核验会剔除未通过原文引用检查的候选事实。屏幕规格本身不推导“多显示几行”或更佳阅读效果。图片只核对对应型号与已确认官方文件，不把外观图当作性能测试。
